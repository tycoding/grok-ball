# Grok Ball

一个会「看」你的 AI 表情球：圆球 + 一双眼睛实时跟随鼠标，内置 **32 种表情状态**（生命周期 / 情绪反应 / 代理工作状态三组），纯 SVG 驱动、单文件、零依赖。

> 灵感来自 Grok 的 Logo 动态效果，但本项目与 xAI / Grok 无关。

## 特性

- **单文件、零依赖**：`index.html` 一个文件即可运行，无需构建、无需 npm、无需外部资源。
- **眼睛跟随鼠标**：基于临界阻尼弹簧 + 指数平滑的注视跟随，眼睛始终「看着」光标。
- **32 种表情**：睡眠、待机、好奇、开心、惊讶、生气、思考中、任务完成、检索资料……全部可切换。
- **完整动画系统**：眨眼、呼吸、自旋甩彩带、撒花、睡眠 zzz、思考环带、表情关键帧序列。
- **可嵌入业务**：提供 `EmotionBall.create()` SDK，可用 `emotionId` 直接对接 AI 输出。

## 快速开始

直接双击打开 `index.html`，或在浏览器中访问。

移动鼠标，右下角和预览区的球都会注视你；点击右下角小球会甩一圈彩带。

## 在业务系统中使用

```js
// 1. 引入 index.html 中的引擎后（或将 <script> 抽离成独立文件），创建实例
const ball = EmotionBall.create('#mount', {
  emotion: '02',      // 初始表情
  color: '#1a1a1a',   // 可选：固定主题色（黑球）
  eyeColor: '#f5f5f5'
});

// 2. 用 emotionId 切换表情（可直接对接 AI 输出）
ball.setEmotion('30');                     // 思考中
ball.handleAIMessage({ emotionId: '30', tips: '正在思考用户问题' });

// 3. 让球注视某个方向（-1..1）
ball.setGaze(0.5, -0.3);

// 4. 订阅状态变化
ball.on('change', e => console.log('切换到', e.id));

// 5. 销毁
ball.destroy();
```

更多表情 ID 对照与高级用法见 [SKILL.md](./SKILL.md)。
